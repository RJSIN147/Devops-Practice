# Docker Hello World Assignment

This folder contains simple Hello World web applications made using Docker.

Folders included:

- `nodejs-app` - Node.js Hello World app with Dockerfile
- `python-app` - Python Hello World app with Dockerfile
- `java-app` - Java Hello World app with Dockerfile
- `Apache-app` - Apache Hello World webpage with Dockerfile
- `React-app` - React Hello World app with Dockerfile
- `nginx-app` - Nginx Hello World webpage with Dockerfile
